# Templates

## Purpose

This directory contains reusable authoring templates for durable Journalism records.

Templates should help preserve important structure without forcing every Investigation, Dossier, Story, or Subject into identical prose.

## Template rules

- A template guides construction; it is not an authority for the facts recorded in an instantiated document.
- Optional sections should remain optional when the underlying work does not support them.
- Templates should evolve from actual use.
- When a template changes materially, existing historical records do not need to be silently rewritten to match the newest form.

Initial templates should remain deliberately small until repeated work shows what is genuinely useful.
