# Environment Images

## Purpose

This directory contains images that are part of the Las Vegas, New Mexico research Body: field photographs, documentary images, scans, maps rendered as images, screenshots used as evidence, and other environment-specific visual records.

Repository-wide interface assets and reusable visual tooling belong in the root `images/` directory instead.

## Evidence handling

When an image is evidentiary, preserve enough context to determine what it depicts and where it came from. Useful metadata may include date/time, location, creator or source, related Subject/Dossier/Investigation, caption, and any known limitations.

Do not treat a filename alone as sufficient provenance.
