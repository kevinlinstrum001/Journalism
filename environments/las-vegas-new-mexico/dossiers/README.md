# Dossiers

## Purpose

This directory contains Dossiers for the Las Vegas, New Mexico environment.

A **Dossier** concentrates durable material about a bounded object of continuing interest, such as an institution, entity, place, infrastructure system, project, program, event, contractor, public office, or recurring problem.

Dossiers are not automatically investigations and do not need to begin with a single question. They are accumulation and orientation records that can support many Investigations and Stories over time.

## A Dossier may contain or reference

- identity and scope;
- chronology;
- key entities and relationships;
- relevant Sources and source artifacts;
- maps, images, datasets, and records;
- known facts and source claims;
- unresolved issues;
- linked Investigations;
- linked Stories;
- activity and update history.

## Operating rule

Prefer one durable Dossier with references into the Body over multiple near-duplicate files created for different Subjects.
