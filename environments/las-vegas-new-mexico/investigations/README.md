# Investigations

## Purpose

This directory contains question-driven Investigations for the Las Vegas, New Mexico environment.

An **Investigation** is a bounded inquiry organized around one or more explicit questions. It uses available evidence to reduce uncertainty, produce findings, update the Body, identify unresolved issues, and generate further leads where appropriate.

## Investigation structure

A durable Investigation should preserve both the starting and resulting state of knowledge.

Useful elements include:

- primary question;
- why the question matters;
- current knowledge at opening;
- open questions;
- candidate explanations or hypotheses when appropriate;
- available sources and leads;
- scope and resolution criteria;
- activities performed;
- sources examined;
- findings;
- contradictions and unresolved issues;
- questions resolved;
- information added to the Body;
- remaining gaps;
- recommended follow-up.

## Findings and commentary

Keep distinct:

- **Finding** — a conclusion supported by collected evidence;
- **Unresolved** — a question or conflict not adequately settled;
- **Commentary** — assessment of framing, methodology, omissions, interpretation, or another source's treatment of the subject.

Commentary may be a legitimate Investigation output, but it should not silently become a factual finding.

## Assignment relationship

The current working model treats Investigation as a specialized **Assignment type**. Assignment Activities record the actual work performed. This directory stores durable Investigation artifacts produced by that work.
