# Environments

## Purpose

This directory contains research environments: durable contextual worlds in which Subjects, Dossiers, Stories, Investigations, Sources, and other Body records can be organized and interpreted.

An Environment provides orientation and routing. It should not be treated as the exclusive owner of every record that references it, and repository location does not by itself establish semantic identity.

## Current environments

- `las-vegas-new-mexico/` — initial working environment for development of the Journalism research system.

Additional environments should be added only when sustained use justifies them.

## Operating principle

The Journalism repository should remain semantically richer than its folder tree. Environment directories provide practical navigation; cross-environment relationships may be represented through registry records, metadata, catalogs, and references rather than file duplication.
