# Catalogs

## Purpose

This directory contains aggregate discovery products that make records in the Journalism Body easier to find, filter, compare, and resume.

Catalogs may index Investigations, Dossiers, Stories, Sources, Subjects, sidecars, or other record families.

## Authority boundary

A catalog is a retrieval surface, not a second source of truth.

> **The catalog points to records; it does not silently replace them.**

When a catalog conflicts with the record it indexes, use the authority assigned to the underlying record and treat the catalog mismatch as something to regenerate or reconcile.

## Expected uses

Catalogs may eventually support questions such as:

- Which Investigations are active?
- Which records involve a particular entity or Subject?
- Which Stories have open research requirements?
- Which Sources have been used before?
- What unresolved questions recur across the Body?
- What should a future session resume next?

Prefer generated catalogs when practical so discovery products remain reproducible.
