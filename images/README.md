# Repository Images

## Purpose

This directory contains repository-wide visual assets used by Journalism tooling, viewers, documentation, interfaces, and reusable publication components.

Environment-specific research evidence should normally live with its environment, for example:

`environments/las-vegas-new-mexico/images/`

## What belongs here

- icons and interface assets;
- reusable diagrams;
- repository branding or navigation graphics;
- viewer assets;
- shared visual templates.

## What does not belong here by default

- ordinary field photographs;
- screenshots collected as evidence;
- environment-specific maps or scans;
- images whose meaning depends on one Investigation or Dossier.

Those should remain near the research context that gives them meaning, with provenance preserved.
